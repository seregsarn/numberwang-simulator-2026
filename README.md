# Numberwang Simulator 2026

A tool for LARP combat training. [Try it out online here](https://seregsarn.github.io/numberwang-simulator-2026/).

For offline use, just put the repo in any random place that's convenient and open `index.html` in your browser of choice, and it should Just Work unless I screwed something up-- there's no dependencies or AFAIK anything that can't run locally.

A friend on Discord requested an app that would just speak random numbers at a configurable delay/etc to help with combat training for a LARP, and he wanted it to be something he could use with minimal technical overhead/knowledge. The ask was pretty small, and it seemed like an interesting challenge to turn it into something completely turn-key, so I dashed this off real quick for him.

(Be advised-- I had Claude crap out most of the UI stuff for me, and haven't polished it at all beyond what was necessary to get the functionality I wanted working, so this is not the nicest UI or the best code underneath it.)

The number-reading sound clips are borrowed from [this library](https://evolution.voxeo.com/library/audio/prompts/) of LGPL-licensed sound bites intended for phone tree software.
